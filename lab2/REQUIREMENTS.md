# Соответствие условию — вариант 12

Автор: Ходько Мария Дмитриевна, группа 3. Порядковый номер в списке — 12.

По таблице выбираются **два направления**: строка — локальная пороговая обработка, столбец — низкочастотные фильтры.

| Требование | Выполнение | Где проверить |
| --- | --- | --- |
| Графический интерфейс | Загрузка изображений, два режима, настройки и одновременное сравнение результатов | `index.html` |
| Два локальных пороговых метода | Локальное среднее минус C и метод Сауволы | `processing.js`, режим «Пороги» |
| Сравнение методов | Один исходник и одинаковое окно, изображения с преимуществом каждого метода, оценка F1 | `results/metrics.json`, раздел 5.1 отчёта |
| Низкочастотные сглаживающие фильтры | Усредняющий и гауссов фильтры с настройкой окна и σ | `processing.js`, режим «Сглаживание» |
| База соответствующих тестовых изображений | Шесть воспроизводимых синтетических примеров с шумом, тенью, низким контрастом и тонкими деталями; для каждого есть эталон | `datasets/`, `DATASETS.md` |
| Подбор примеров для сравнения | Среднее лучше сохраняет бледный текст, Саувола лучше подавляет фактуру и шум фона при заданных параметрах | `results/faint-comparison.png`, `results/texture-comparison.png` |
| Корректность | Восемь групп численных проверок и девять проверок интерфейса WebKit | `tests.js`, `results/ui-checks.json` |
| Пояснения | Формулы, параметры, обработка границ, сложность алгоритмов, метрики и выводы | `report.pdf`, `report.tex`, `README.md` |
| Скриншоты для отчёта | Шесть снимков приложения; два включены в PDF, сравнения результатов также включены | `screenshots/`, `report.pdf` |

Условие о наилучшем и наихудшем коэффициенте сжатия относится к вариантам сжатия. В варианте 12 выбрана обработка, поэтому алгоритм сжатия и оценка коэффициента не требуются. Глобальные пороги, морфология, гистограммное выравнивание и фильтры резкости принадлежат другим строкам и столбцам таблицы.

Синтетическая база описана явно; преимущества не заявляются для всех реальных изображений. Собственные сканы и фотографии можно загрузить в интерфейсе.
