# Цветовые модели RGB, CMYK и HSV

Лабораторная работа №1 по компьютерной графике. **Ходько Мария Дмитриевна, группа 3.** Чётный вариант: CMYK — RGB — HSV.

Веб-приложение для интерактивного выбора цвета и преобразования между тремя цветовыми моделями. Работает в браузере без установки зависимостей и подключения к интернету.

![Интерфейс приложения](lab1/screenshots/01-overview.png)

## Возможности

- Задание точных компонентов RGB, CMYK и HSV в числовых полях.
- Плавное изменение каждой компоненты ползунком.
- Выбор цвета из палитры в каждой панели.
- Автоматический пересчёт остальных моделей при любом изменении цвета.
- Общий образец цвета, ввод HEX и готовые примеры.
- Проверка диапазонов и обработка некорректного ввода.

## Запуск

1. Нажмите **Code → Download ZIP** и распакуйте архив.
2. Откройте `lab1/index.html` в браузере.

Можно также клонировать репозиторий:

```bash
git clone https://github.com/immaryllis/cg-color-models-rgb-cmyk-hsv.git
cd cg-color-models-rgb-cmyk-hsv
```

Откройте файл `lab1/index.html`. Сервер, Node.js и сборка не требуются.
